One deadpan one-star review written by a house cat about its human, under 200 characters.
`main.py` writes the review to `/output/entry.txt` (deterministic, with a 1–200 char self-check).

Entry: "One star. The human moved my favourite sunbeam, served dinner three minutes late, and then expected purring. I knocked a glass off the table in protest."
